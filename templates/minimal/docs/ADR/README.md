# Architecture Decision Records

Use one ADR for each durable architecture/product engineering decision whose rationale future maintainers or AI agents must preserve.

## Naming

`ADR-0001-short-name.md`

## Template

```md
# ADR-0000 — Title

Status: Proposed | Accepted | Deprecated | Superseded
Date: YYYY-MM-DD

## Context
## Decision
## Options considered
## Why
## Consequences
## Evidence
## Supersedes
## Superseded by
```
