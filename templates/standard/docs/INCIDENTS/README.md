# Incidents

Use significant incidents to preserve failure memory.

## Template

```md
# INC-YYYY-NNN — Title

Status:
Detected:
Affected versions/commits:

## Symptom
## Impact
## Root cause
## False leads
## Fix
## Evidence
## Regression test
## New invariant
## Follow-up
```

Do not record every typo. Record failures whose forgotten cause could lead to regression, repeated investigation, unsafe retesting, or architecture mistakes.
