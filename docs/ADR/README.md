# Architecture Decision Records

ADRs preserve **why** a durable project decision was made.

Use one file per significant decision.

## Naming

`ADR-0001-short-name.md`

## Template

```md
# ADR-0000 — Title

Status: Proposed | Accepted | Deprecated | Superseded
Date: YYYY-MM-DD

## Context

What problem or constraint caused this decision?

## Decision

What was decided?

## Options considered

What realistic alternatives were considered?

## Why

Why was this option selected?

## Consequences

What becomes easier, harder, or constrained?

## Evidence

What repository/runtime evidence supports the decision?

## Supersedes

ADR or decision replaced by this one, if any.

## Superseded by

Newer ADR, if any.
```

Do not use ADRs as a chronological task log.
